# ASTRA-8 — Бортовий AI-аналітик космічної місії

Консольний (CLI) інженерний ШІ-асистент на мові Python, який працює повністю локально поверх рантайму **Ollama** через OpenAI-сумісний HTTP API. Застосунок призначений для аналізу логів телеметрії, діагностики несправностей систем космічного апарата, технічного перекладу документації та виконання інженерних розрахунків у системі СІ.

---

## Системні вимоги

- **ОС:** Windows 10/11, Linux або macOS.
- **Апаратне забезпечення:** GPU NVIDIA з обсягом відеопамʼяті від 10–12 GB VRAM (наприклад, NVIDIA GeForce RTX 3060 12GB) для комфортної роботи 8-бітної моделі повністю у відеопамʼяті.
- **Програмне забезпечення:**
  - [Ollama](https://ollama.com/download) (версії 0.1.30 або новішої).
  - **Python** версії 3.10 або новішої.
  - Бібліотека `openai` для Python.

---

## Встановлення та підготовка

### 1. Завантаження мовної моделі в Ollama

Відкрийте термінал та завантажте 8-бітну квантизовану модель `llama3.1:8b-instruct-q8_0` (розмір ≈ 8.5 GB):

```bash
ollama pull llama3.1:8b-instruct-q8_0
```

Переконайтеся, що сервер Ollama запущений у фоні (у Windows він стартує автоматично, у Linux можна виконати `ollama serve`). API має бути доступним за адресою `http://localhost:11434/v1`.

### 2. Налаштування Python-середовища

Перейдіть у кореневу теку лабораторної роботи (`lab4/`), створіть віртуальне середовище та встановіть клієнтську бібліотеку `openai`:

**Для Windows (PowerShell):**

```powershell
python -m venv venv
.\venv\Scripts\activate
pip install openai
```

**Для Linux / macOS:**

```bash
python3 -m venv venv
source venv/bin/activate
pip install openai
```

## Запуск застосунку

Перебуваючи в активованому віртуальному середовищі (`venv`), запустіть головний скрипт із теки `app/`:

```bash
python app/main.py
```

### Команди керування в інтерфейсі

- Введіть будь-яке інженерне запитання або вставте фрагмент логу телеметрії та натисніть `Enter`.
- `/clear` — очистити поточну історію діалогу (`messages`), щоб попередній контекст не впливав на нову задачу.
- `вихід` (або `exit`, `quit`) — коректно завершити сеанс звʼязку та вийти з програми.

## Параметри генерації та архітектурні рішення

У файлі `app/main.py` закладено такі параметри запиту до локального сервера:

- **`model="llama3.1:8b-instruct-q8_0"`** — 8-бітна квантизація забезпечує високу якість української мови та точність технічної термінології без критичної деградації ваг.
- **`temperature=0.3`** — низька випадковість генерації зменшує ризик вигадування неіснуючих фактів (галюцинацій) під час технічного аналізу та обчислень.
- **`max_tokens=600`** — запобіжник від нескінченного зациклення моделі, якого достатньо для розгорнутої відповіді або фрагмента коду.
- **`stream=True`** — потокове виведення тексту токен за токеном у реальному часі.
- **`timeout=60.0`** — обмеження часу очікування відповіді від сервера.
- **`num_ctx = 2048`** — (значення за замовчуванням в Ollama при роботі через OpenAI-сумісний API) — довжина контекстного вікна в токенах. Цього обсягу достатньо для збереження системного промпту, поточної історії діалогу та фрагментів логів телеметрії, і водночас він не перевантажує VRAM зайвим KV-кешем (для 8-бітної моделі 8B контекст у 2048 токенів займає лише ~0.3–0.5 GB VRAM, залишаючи максимум памʼяті під самі ваги).
